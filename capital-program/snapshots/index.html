Snapshots

A snapshot freezes every spend plan, budget and gate as it stands. Later edits never change it, so planned-vs-actual history keeps itself.

Quarters that end on or before the as-of date show actuals in this snapshot.

One snapshot per FY can be the baseline. Setting this one replaces the current baseline for that FY.
