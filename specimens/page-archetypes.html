How to read this: the shell + four modern archetypes compose from existing esa-* legos today. Three regions surface real hub gaps — a data-table and a map lego — that gate the Grid, Map and Record archetypes. That dependency sets the build order: shell → Hub / Sub-hub / Report (no new legos) → Grid (port table) → Map → Record (reuses map).

Next: lift each archetype to a high-fidelity, CB-Fish-skinned specimen — one at a time — then promote the stable shell + skeletons to the hub.
