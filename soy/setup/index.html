Set up FY2028

Dates

Pre-filled from the standard pattern. Each stage is due the day before the next one opens; PM proposed defaults to 4 weeks.

StageOpensDueLength

Carry forward last year’s items

Every FY2027 item (project + fund + account type) is listed. Items whose project has ended or that are no longer non-Accord expense start unchecked, with the reason. You can re-check any of them.

Add new projects

Eligible non-Accord expense projects that weren’t in last year’s cycle. Select the ones to add; they start with no baseline, so you’ll enter their EWB proposed amounts by hand.

No new projects to add

Every eligible project is already in the cycle.

Cost-of-living adjustment (COLA)

Filter the table to the projects that get the COLA, enter the rate, and check each baseline before and after. COLA updates the FY2028 SOY baseline only — it no longer rewrites project baselines directly.
